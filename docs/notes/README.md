# Learning notes

Short, review-friendly notes for each chapter of the book: the main ideas, rules of thumb, and the traps we hit while building them here, including bugs in the book's own sample code.

Each page has the same sections:

- **The idea**: the chapter in a few sentences.
- **Key points**: what to remember.
- **Rules of thumb**: decisions you can apply directly.
- **Traps**: what went wrong, or would have, when we built it.
- **In this repo**: where the code is.
- **Check yourself**: questions to answer from memory.
